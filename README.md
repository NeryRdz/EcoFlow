# 🌿 EcoFlow

> **A circular economy platform for Aguascalientes, México.**  
> Connecting citizens, small businesses, and companies to exchange, reuse, and recycle materials — reducing waste and building a more sustainable community.

---

## 📌 About the Project

EcoFlow is a dual-platform initiative (web + mobile app) developed as a response to the environmental challenges.

The platform enables users to:
- 📍 **Post and discover** recyclable or reusable materials on an interactive map
- 🔄 **Exchange, donate or sell** materials within the community
- 📚 **Learn** about circular economy through integrated educational modules
- 🤝 **Connect** with other citizens, businesses and organizations

This project aligns with the **UN Sustainable Development Goals (SDGs)**, particularly those related to responsible consumption, climate action, and sustainable cities.

## 🎯 Core Features

- 🗺️ **Interactive map** — visualize material exchange points across Aguascalientes
- 👤 **User authentication** — register, log in, and manage personal listings
- 📦 **Material listings** — post items with description, quantity, and contact info
- 🎓 **Educational section** — FAQ and content about circular economy practices
- 📊 **Admin dashboard** — manage users and publications (mobile version)
- 🏆 **Achievement system** — gamified progress to reward active community members
